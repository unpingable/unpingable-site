Constellation Research About Writing

James Beck

Research and working software on a question 26 years in operations and reliability kept asking: when an automated system reports that something worked, how does anyone know it did?

“The command returned” and “the intended thing happened” are different facts. The gap matters for deploy pipelines and scheduled jobs, and it matters more now that AI coding agents report their own success: a worker’s report of completion is not evidence that the intended state exists. This site collects the software, papers and proofs that work has produced.

Current work

  • ConstellationSystems forget how they know. An experimental system for separating work from the evidence, authority and acceptance used to decide whether that work succeeded. The main current project. Alpha; not production-ready.
  • ABSDA small experimental x86-64 operating system, built partly to test the same ideas below the application layer.
  • PapersFormal and semi-formal work on timing, verification lag and stability in hierarchical systems, mostly the Δt series.
  • Lean proofsSelected claims from the Δt series, machine-checked in Lean 4. They prove the boundaries of refusal classes, not that any deployed system is safe.
  • WritingEssays and notes, kept on a separate site.
