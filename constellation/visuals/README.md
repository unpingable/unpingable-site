# Visual assets for the recorded local cycle

These assets explain an agent-driven local qualification. A deliberately stopped nginx systemd unit was started through the native command sequence. They do not establish HTTP health, a human usability trial, current runtime state or successor-package qualification.

## Asset roles

| Asset | Role |
|---|---|
| `architecture.svg` | Component ownership and separate observation/action paths. |
| `evidence-flow.svg` | Native command order; read `CYCLE.md` for selected receipts. |
| `operator-workflow.svg` | Participant responsibilities; a guide, not another command transcript. |
| `active-before-*`, `inactive-*`, `active-after-*` | Three states from the same recorded N session. Use desktop with mobile as the responsive alternative. |
| `CYCLE.md` | Recorded final N commands and selected active enum branches. |
| `EARLIER-REFUSAL.md` | Exact commands and complete refusal JSON from the separate earlier L session. |

SVG files have tight view boxes, titles and descriptions. Matching Mermaid files retain the conceptual relationships for editing. They are schematic source, not recorded output. Edit both descriptions when changing a relationship.

## Recorded page treatment

HTML files are identity-redacted offline copies with scripts, network and actions disabled. Only the added amber capture banner was replaced. Everything below that banner preserves the source page; screenshots crop to the complete title and status/attempt lines. The original “live” labels and relative ages are frozen in these static captures. The redacted short identity in the active-after page identifies the boot, not the preparer. “Operational EDA” is the recorded UI breadcrumb, while “Operational ECAD” is the receipt owner/schema naming; both original labels remain visible.

N means the final recorded session; L means the separate earlier refusal session. L was not re-run on N. The final N transcript's missing identity is an argument validation error. A self-supplied preparation token is not authentication. These commands do not show who authorizes merely because they all use `sudo`.

## Captions and alternative text

`MANIFEST.json` records hashes, dimensions where applicable, captions and alternative text. Use the supplied descriptions when embedding images; retain the schematic/recorded distinction. Private source mappings and execution records stay outside this directory.

## Small glossary

- **NQ:** native observation acquisition and history custody.
- **Monitor:** projection of published owner evidence.
- **Workbench:** the read-only inspection page in these captures.
- **Agent Governor (AG):** native attempt decision, authorization and settlement.
- **Docket / standing:** scoped execution eligibility consulted by the native action path.

No publication, deployment or operational acceptance is implied by these presentation assets.
