Constellation release notice inventory

Project-authored code and release glue are Apache-2.0; compiled third-party
components retain their respective licenses and attributions. The complete
release, not an unaccompanied .deb, is the distribution unit. Redistribute
individual native packages only with this complete notice collection.

LICENSE-INDEX.json records seven exact accepted component sources, six Cargo
locks and 480 registry package names/versions/checksums with verbatim declared
license expressions. It is a conservative full-lock superset, including build,
development, unselected and non-Linux dependencies, not an exact link map.
No dependency source is redistributed merely because it appears in a lock.
NESTED-NOTICES.json adds nested copyright/license notices from retained sources.
Rust standard-library COPYRIGHT and supplied texts are included; the compiler
is not distributed. Component NOTICEs: Monitor, Nightshift, Docket and LA.

SQLite is bundled into selected native executables through libsqlite3-sys;
its source is public domain, while the Rust wrapper keeps its declared license.
The SQLCipher alternative is not selected in this Ubuntu SQLite build.
Ordinary system libraries and separately obtained central OCI images are
installation dependencies, not redistributed artifact bytes.

The first-party scope grant is ../LICENSE and ../NOTICE. Third-party text
files retain original terms. See ../THIRD-PARTY-LICENSES.md and
../DISTRIBUTION.md for selected web assets and the redistribution boundary.
