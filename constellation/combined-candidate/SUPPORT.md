# Supported scope and limits

Ubuntu 22.04 amd64 is the combined candidate baseline. Exact ordinary packages and documented fixed native APIs are selected. The human newcomer study is prepared and has not been run. This candidate is prepared: not approved, not published, not distributed and not Beta Candidate 1. Use it only for a supervised private-VM session of up to four hours, ended the same day; nothing here claims unattended operation.

Live current-forward Workbench diagnosis and governed native continuation were qualified, within bounds, on predecessor candidates. Qualification of this exact archive is recorded in `QUALIFICATION.json` beside the archive; QUALIFICATION-SUMMARY.json lists only what is carried from predecessors by package byte identity. The UI is read-only; actions use authenticated POST requests to the separate native reader/action facade; its GET reads are unauthenticated. Both documented first-run paths require loopback access confinement. The prepared disposable fixture has one enrolled systemd unit and no HTTP capability, external page route or model budget. The `try/` path governs the packaged `nginx.service` instead; it observes that unit's systemd state only, not whether nginx serves HTTP. It is not a general-purpose installation wizard or universal diagnostic engine. Known limitations, including the finite NQ capacity ceiling and the fact that AG's `completed` state is not the result of the Start, are in [KNOWN-ISSUES.md](KNOWN-ISSUES.md).

This candidate includes NQ with bounded retention (issue #27 remains open): dependency-aware expiry and a persisted capacity envelope. On this trial the store reaches its 1 GiB per-file ceiling after roughly 40 hours by arithmetic, before anything expires; controlled capacity refusal is then the expected result (derived from code reading and component-level runs, not exercised on a guest) and no same-VM recovery is supplied. No seven-day availability or arbitrary workload capacity is established. The 8 October archive is retired as a release candidate; its unbounded-store failure remains documented as predecessor history.

## Advanced reference scope

Kubernetes acquisition/diagnosis is GET-only and optional. Bounded Tier-5 standing covers the accepted reveal campaign; Kubernetes execution does not exist. `NO_ADMITTED_KUBERNETES_EXECUTOR` is an honest refusal. Acquisition does not invent NQ/Pulse standing. The packaged CLI requires explicitly supplied bounded credential custody, TLS trust and settings; it does not auto-discover production clusters. Historical reveal exports are labeled **AS RECORDED** and retain exact bytes. They are not current live state.

The deterministic remediation consumer (v1) is installed disabled; nothing in the try path or the manual path enables it, and no automatic remediation has been run on these packages. Agentic remediation v2 was qualified separately on other package bytes; it is optional, disabled by default and not demonstrated on this candidate. The `reference/` installation path and `constellation-host-posture.service` have not been run with this NQ package; do not use them with this candidate. FreeBSD acceptance applies only to its separately qualified path, not these Ubuntu packages. Observer-only nodes, wider diagnostic-depth implementation, broader targets, Kubernetes execution, Silverblue, federation, CI/CD/build management, credential-provider integrations and hardware-backed authority remain later beta work. No private machine identity or hostname belongs in public documentation.

Some unchanged native CLI version output lacks a source commit (including LA’s legacy `version` record). Use the exact package, source and installed-byte manifests; do not treat `unknown`/0.0.0 display metadata as a substitute identity or an inferred newer build.

The optional read-only LA projection is a fixed owner-exported accounting snapshot, not an automatic live publisher, budget administration or operational authority. The native legacy LA version command reports its accepted crate version 0.0.0/unknown source; use exact package/source/runtime hash manifests for identity. Historical NQ 0.2.4 predecessor packages remain private recovery custody and are omitted from this candidate; the supplied Workbench version-only rollback is documented in the day-two runbook.
