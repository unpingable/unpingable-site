# Supported scope and limits

Ubuntu 22.04 amd64 is the combined candidate baseline. Exact ordinary packages and documented fixed native APIs are selected. Human stranger-operability is pending owner review and a separate human run. This is not Beta Candidate 1.

Accepted live current-forward Workbench diagnosis and governed native continuation retain their bounded standing. Source-free packaged integration is recorded separately in QUALIFICATION-SUMMARY.json. The UI is read-only; actions use the documented authenticated native API escape. The prepared disposable fixture has one enrolled systemd unit and no HTTP capability, external page route or model budget. It is not a general-purpose installation wizard or universal diagnostic engine.

Kubernetes acquisition/diagnosis is GET-only and optional. Bounded Tier-5 standing covers the accepted reveal campaign; Kubernetes execution does not exist. `NO_ADMITTED_KUBERNETES_EXECUTOR` is an honest refusal. Acquisition does not invent NQ/Pulse standing. The packaged CLI requires explicitly supplied bounded credential custody, TLS trust and settings; it does not auto-discover production clusters. Historical reveal exports are labeled **AS RECORDED** and retain exact bytes. They are not current live state.

Agentic remediation v2 is separately qualified, optional and disabled by default. FreeBSD acceptance applies only to its separately qualified path, not these Ubuntu packages. Observer-only nodes, wider diagnostic-depth implementation, broader targets, Kubernetes execution, Silverblue, federation, CI/CD/build management, credential-provider integrations and hardware-backed authority remain later beta work. No private machine identity or hostname belongs in public documentation.

Some unchanged native CLI version output lacks a source commit (including LA’s legacy `version` record). Use the exact package, source and installed-byte manifests; do not treat `unknown`/0.0.0 display metadata as a substitute identity or an inferred newer build.

The optional read-only LA projection is a fixed owner-exported accounting snapshot, not an automatic live publisher, budget administration or operational authority. The native legacy LA version command reports its accepted crate version 0.0.0/unknown source; use exact package/source/runtime hash manifests for identity. Historical NQ 0.2.4 predecessor packages remain private recovery custody and are omitted from this download; the supplied Workbench version-only rollback is documented in the day-two runbook.
