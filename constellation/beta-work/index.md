## Cross-program dependencies and priority

Required release work follows package/build identity and closure (PA-11/12), AG/Docket custody, current NQ delivery/recovery, Nightshift/Foreman temporal/provider lifecycle, Monitor generation limits and Switchyard runtime export. PA-13 retains site/deployment recurrence-history, cadence and generation rotation planning; components do not absorb target adapters. The initial deployment/send/recurrence absence is superseded by owner records and is not a new issue. No active application or production work is executed here.

Registry adoption (PA-01), ADR/traceability/change-impact design (PA-03/04), integration train (PA-05), certificates/lifecycle (PA-06), qualification-tooling ownership (PA-07) and work contracts (PA-09) reduce future coordination cost. They do not gate operator-beta merely because alpha exposed them. Program ownership of the map does not assign the mapped semantics.

Post-beta: substrate/archaeology practice, experimental Docket executor promotion, Continuity reliance-scope change, Linear Accountant thaw and Wicket semantic promotion. Broader multi-governor discovery/arbitration/delegation/federation, generic OTLP rollout, k3s, additional workloads and broad UI redesign retain their existing deferred scopes; no implementation or duplicate successor issue is authorized.
