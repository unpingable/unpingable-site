Names used on this page

Each name is one small program; the components page has the details. The words composition, profile, exhibit and promotion are defined below.

AG
Decides whether one exact piece of work may run, and grants permission for that one run.
Docket
Keeps custody of an authorized attempt: sends it once, records the outcome, and reconciles an uncertain one by reading rather than repeating.
NQ
Evaluates a narrowly defined question from recorded evidence, or refuses when the evidence is missing or stale.
Maude
Writes and checks the exact plan of work before anyone authorizes it.
Nightshift
Tracks work and conditions over time and proposes the next task.
Pulse
Checks whether current evidence still supports one specific statement.
Switchyard
Runs bounded requests to a model provider, used here for the independent review of a plan.
App Server
The agent runtime, built from public Codex source, that Switchyard drives for that review; see guides and source.

Indeterminate-effect demo (refund with a lost reply)

exhibit cold-clone qualified; source branch not merged

An agent reports a refund done after the reply was lost. Docket, built from source, records the attempt as indeterminate, sends nothing twice, and settles success or failure only on a separate observer's read of the provider's ledger. A second run with the request lost ends in failure under the same agent claim. Docket is real; the authorization signer (a stand-in reproducing AG's published test vector), the payment provider, the faulty network link and the agent are local stand-ins. Everything runs on one host under one clock.

verified 2026-09-25
run-003: an anonymous HTTPS clone of the demo branch into a fresh Debian 12 virtual machine, with the network cut off for the build and the run; the demo exited 0 and its independent check passed 53 of 53 checks.
evidence
demo source (unmerged branch) · transcript · check output · recording
promotion
The branch must be merged before the demo counts as part of Docket. Independence holds because this demo's worker delegates reconcile to the observer; Docket does not pin that configuration, so it is not a general guarantee. Using AG itself, a remote provider, or several observers would each need separate evidence.

How to read the labels

The ledger and the archive use two small vocabularies, so that a reader never has to guess whether something is an idea, a design proposal, a working specimen, a qualified composition, or deployed evidence.

Four kinds of object

artifact
An implemented system with a bounded, independently inspectable claim.
composition
A specific relationship between artifacts that has actually been exercised. Compositions are earned individually and dated; none of them generalize.
exhibit
A behaviour you can presently inspect or run.
proposition
Candidate architecture under investigation. Named, not ratified, and usually not built.

Other terms

profile
One named, pinned composition with a released guide, such as reviewed-local-copy/v1. An integration release qualifies a named profile.
promotion
Strengthening a row’s claim, for example from release candidate to release. It happens only by an explicit editorial decision once the stated condition is met.
settlement
The final recorded outcome of an attempt: success or failure, with the evidence it rests on.
reconcile
Finding out what happened to an uncertain attempt by reading evidence, never by repeating the attempt.
alpha-exit
The work of getting from the alpha integration releases to a first packaged release.

Four kinds of thing shown

schematic
A designed explanatory diagram or normalized trace. It teaches the shape of the system. It is not output.
captured run
Literal bytes from an actual execution, carrying the command, the version, and the date it was run.
rendered
A readable presentation generated from a real machine artifact. The raw artifact stays reachable.
cited
A claim whose warrant is a document in a public repository, linked at the point of use.

Where a distinction is not yet earned, this site says so rather than smoothing it. Synthetic fixtures appear only where they are identified as synthetic and used to demonstrate conditional behaviour — never as testimony about a real estate. Terms of art are defined in the glossary.
